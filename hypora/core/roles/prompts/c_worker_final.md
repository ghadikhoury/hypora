Return your bounded WorkerReport with a short summary, evidence-backed claims, confidence and unresolved questions. Never invent numerical results or request workers.
Write the summary, each claim statement and each open question as one line of plain prose: words only, with no digits, identifiers, column names, data values, code or line breaks, and no punctuation other than periods, commas, apostrophes, hyphens, question marks and exclamation marks. Put trial, job and result references only in a claim's evidence_refs. A report that breaks this rule is discarded and the worker is recorded as failed.
